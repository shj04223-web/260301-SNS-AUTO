# 인스타그램 협찬 게시글/릴스 작성 운영 흐름

## 1) 캠페인 정보 수집

입력: 체험단 링크 (예: `https://www.stylec.co.kr/trials/83642`)

아래 항목을 우선 수집합니다.
- 제공내역
- 검색 키워드
- 체험단 미션
- 유의사항
- (가능하면) 마감일, 업체명

> 팁: 캠페인 원문 문장을 그대로 보관하고, 요약본을 별도로 작성하면 검수/수정이 쉬워집니다.

---

## 2) Notion CO-WORK LIST 입력

Notion 데이터베이스(예: `CO-WORK LIST`)에 아래 항목을 채웁니다.

- 마감일
- 체험단업체
- 진행상태
- 캠페인정보
- 포스팅 정보

운영 권장 상태값 예시:
- 정보수집
- 초안작성중
- 검수중
- 업로드완료

---

## 3) 리서치(학습)

초안 품질을 높이기 위해 다음을 반영합니다.

- 캠페인 키워드 우선순위 정렬 (필수/권장)
- 제품명 + 핵심 효능/경험 키워드로 후기 조사
- 후기에서 자주 언급되는 표현 추출 (향, 텍스처, 지속력, 사용상황 등)
- 과장/의학적 단정/오인 가능 표현 제거

---

## 4) 콘텐츠 초안 생성

### A. 피드 게시글

구성 권장:
1. 훅(첫 문장)
2. 사용 계기/문제상황
3. 사용감/핵심 포인트 2~3개
4. 개인 경험 기반 결론
5. CTA(저장/댓글 유도)

### B. 릴스

동시에 2종을 만듭니다.
- 릴스 대본(장면별)
- 릴스 게시글 버전(캡션)

릴스 대본 구성 권장:
- 0~2초: 문제 제기 훅
- 3~8초: 제품 제시 + 핵심 장점
- 9~15초: 사용 장면/결과
- 16초~: 요약 + CTA

---

## 5) 최종 점검 체크리스트

업로드 전 체크:
- [ ] 필수 키워드 누락 없음
- [ ] 체험단 미션 반영 완료
- [ ] 금지 문구/주의사항 위반 없음
- [ ] 광고/협찬 표기 정책 준수
- [ ] 브랜드 톤과 개인 톤 균형 확인
