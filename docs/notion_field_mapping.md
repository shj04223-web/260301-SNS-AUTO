# Notion CO-WORK LIST 필드 매핑 가이드

아래는 체험단 링크 원문을 Notion 관리 항목으로 변환하는 기준입니다.

| Notion 필드 | 입력 기준 | 예시 |
|---|---|---|
| 마감일 | 캠페인 페이지의 신청/업로드 마감일 | 2026-03-15 |
| 체험단업체 | 캠페인 운영사 또는 브랜드명 | 스타일C / OO브랜드 |
| 진행상태 | 현재 작업 단계 | 정보수집 |
| 캠페인정보 | 제공내역 + 검색 키워드 + 미션 + 유의사항 요약 | "제공내역: ... / 키워드: ..." |
| 포스팅 정보 | 게시글/릴스 타입, 업로드 채널, 초안 링크 | "IG 릴스 + 캡션 초안 v1" |

## 입력 텍스트 포맷 권장

### 캠페인정보

```text
[제공내역]
...

[검색 키워드]
...

[체험단 미션]
...

[유의사항]
...
```

### 포스팅 정보

```text
콘텐츠 타입: 인스타 피드 / 릴스
초안 버전: v1
핵심 메시지: ...
필수 키워드: ...
```
