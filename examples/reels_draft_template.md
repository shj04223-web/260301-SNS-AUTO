# 인스타그램 릴스 초안 템플릿

## 1) 릴스 대본 (장면별)

- 0~2초 (훅)
  - 자막: "_____ 때문에 아직도 고민해?"
  - 내레이션: "저도 이거 때문에 꽤 오래 헤맸어요."

- 3~8초 (제품 소개)
  - 자막: "요즘 써보는 _____"
  - 내레이션: "이번에 써본 건 _____인데, 첫인상이 꽤 좋았어요."

- 9~15초 (사용감/포인트)
  - 자막: "포인트 1 / 포인트 2 / 포인트 3"
  - 내레이션: "특히 _____, _____, _____이 만족스러웠어요."

- 16~22초 (결론 + CTA)
  - 자막: "_____ 찾는다면 참고!"
  - 내레이션: "비슷한 고민 있던 분들은 저장해두고 비교해보세요."

## 2) 릴스 캡션(게시글 버전)

요즘 ______ 찾고 있었는데, 직접 써보니 생각보다 ______가 좋았어요.

제가 느낀 핵심은
- ______
- ______
- ______
