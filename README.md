# SNS 체험단 캠페인 자동화 워크플로우

이 저장소는 아래 작업을 반복 가능하게 만드는 데 목적이 있습니다.

1. 체험단 링크(예: StyleC)에서 핵심 정보 수집
2. Notion `CO-WORK LIST`에 관리용 항목 저장
3. 가이드라인/키워드 + 외부 후기 조사 기반으로 초안 생성
   - 인스타그램 피드 게시글 초안
   - 릴스 대본 + 릴스용 캡션 초안

## 폴더 구조

- `docs/workflow.md`: 전체 운영 흐름
- `docs/notion_field_mapping.md`: Notion 입력 항목 매핑
- `examples/`: 실전에서 바로 수정해 쓸 수 있는 예시 템플릿

## 빠른 사용 순서

1. `examples/intake_template.md`에 캠페인 원문 내용을 복사합니다.
2. `docs/notion_field_mapping.md`를 참고해 Notion 필드에 정리합니다.
3. `examples/post_draft_template.md` 또는 `examples/reels_draft_template.md`로 초안을 만듭니다.
4. 톤/말투/해시태그를 개인 브랜딩에 맞게 보정 후 최종 업로드합니다.
